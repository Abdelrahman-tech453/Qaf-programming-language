# Qaf editor highlighting

Syntax highlighting for Qaf `.qf` files.

- Sublime Text: `sublime/Qaf.sublime-syntax`
- Vim: `vim/syntax/qaf.vim` and `vim/ftdetect/qaf.vim`
- Neovim: `neovim/qaf.lua`

Qaf syntax covered: keywords, types, booleans, numbers, function calls, operators, strings/escapes, and `#` comments.
